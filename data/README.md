# Data

All files come from the BibFusion run documented in `provenance/` (BibFusion 1.0.0, prepared 2026-10-09). Checksums for every file are in `SHA256SUMS`; `provenance/configuracion.json` also records the SHA-256 of the three original exports (`scopus.csv`, `wos.txt`, `scimago.csv`).

```bash
sha256sum -c data/SHA256SUMS     # run from the repository root
```

## Folders

| Folder | Content |
|---|---|
| `input/` | Original exports: `scopus.csv` (230 records), `wos.txt` (200 records), `scimago.csv.gz` (SCImago journal rankings, gzip-compressed because the original, 240 MB, exceeds GitHub's 100 MB file limit). Restore with `gunzip -k data/input/scimago.csv.gz`; the decompressed file has the same SHA-256 recorded in `provenance/configuracion.json`. |
| `bibfusion_output/scopus/` | Final BibFusion tables built from the Scopus export: `Article`, `ArticleAuthor`, `Author`, `AuthorAlias`, `AuthorConflicts`, `AuthorPerson`, `Affiliation`, `Citation`, `Journal`, `scimagodb`. |
| `bibfusion_output/scopus/intermediate/` | Numbered intermediate tables of the pipeline (`1_temp_...` to `10_temp_...`), `6_scopus_ref_enriched`, `scimago_raw`, `scopus_author_raw`, `scopus_author_enriched`. |
| `bibfusion_output/wos/` and `wos/intermediate/` | Same structure for the Web of Science export (plus `enrich_wos_ref`). |
| `bibfusion_output/integrated/` | Integrated Scopus + WoS tables used by the manuscript: `All_Articles` (16,716 rows), `All_Authors` (28,258), `All_ArticleAuthor` (41,271), `All_Citation` (22,404), `All_Affiliation` (45,794), `All_Journal` (1,219), `All_Scimagodb` (1,151). Row counts match `reference/resumen_tablas.csv`. |
| `reference/` | `country.csv` (country codes) and `resumen_tablas.csv` (row and column counts of the integrated tables). |

## What was left out of the repository

- `recuperacion/*.pkl.gz` (5 BibFusion cache files, pandas 2.2.3 pickles). They are regenerated by BibFusion, are not needed to reproduce the analysis, and loading a pickle from an untrusted source can execute code.
- Second copies of `scopus.csv`, `wos.txt` and `scimago.csv` that BibFusion wrote into its results folder; they are byte-identical to the files in `input/` (same SHA-256).

## Notes

- `provenance/COMPLETADO.json` reports the state `archivos_generados_pendientes_de_auditoria` (files generated, pending audit).
- `provenance/environment_freeze.txt` is the full package list of the environment that ran BibFusion (renamed from `requirements.txt`). The analysis in `src/` needs only the packages in the top-level `requirements.txt`.
